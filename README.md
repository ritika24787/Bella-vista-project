# Bella-vista Restaurant 🍕

Bella-vista is a simple Italian restaurant website created using HTML and CSS.
This project is designed to show a clean and attractive restaurant webpage with basic navigation, menu, about section, contact form, and footer.

## Features

* Responsive navigation bar
* Attractive hero section
* Restaurant menu section
* About Bella-vista section
* Contact and reservation form
* Submit Reservation button
* Footer with quick links and opening hours
* Hover effects on buttons and links
* Responsive design for different screen sizes

## Technologies Used

* HTML5
* CSS3

## Project Sections

### 1. Home

A hero section with a welcome message and buttons for viewing the menu and making a reservation.

### 2. Menu

Shows some Italian food items with their descriptions and prices.

### 3. About

Contains a short story about Bella-vista restaurant along with an image.

### 4. Contact

Contains restaurant contact details and a reservation form.

### 5. Footer

Includes restaurant information, quick links, opening hours, and social media links.

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The Bella-vista restaurant website will open.
